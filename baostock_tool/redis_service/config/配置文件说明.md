# 配置文件使用说明

## 配置文件位置

配置文件位于: `config/config.ini`

## 配置文件结构

### 1. [database] - 行情源数据库配置

```ini
[database]
host = localhost              # 数据库主机地址
port = 3306                  # 数据库端口
user = root                  # 数据库用户名
password = your_password     # 数据库密码
database = stock_db          # 数据库名称
charset = utf8mb4            # 字符集
pool_size = 5                # 连接池大小
connect_timeout = 10         # 连接超时时间（秒）
```

### 2. [redis] - Redis 服务器配置

```ini
[redis]
host = localhost             # Redis 主机地址
port = 6379                  # Redis 端口
db = 0                       # Redis 数据库编号
password =                   # Redis 密码（留空表示无密码）
encoding = utf-8             # 编码格式
decode_responses = true     # 是否自动解码响应
socket_timeout = 5           # Socket 超时时间（秒）
socket_connect_timeout = 5   # Socket 连接超时时间（秒）
max_connections = 50        # 最大连接数
```

### 3. [backtest] - 回测配置

```ini
[backtest]
start_date = 20241001                    # 回测开始日期
end_date = 20241008                      # 回测结束日期
strategy_id = MA10_BREAKTHROUGH         # 选股策略ID
use_strategy = true                     # 是否使用选股策略
default_selection_count = 10            # 默认选股数量（不使用策略时）
strategy_params = {...}                 # 策略参数（JSON格式）
trade_dates =                            # 交易日列表（可选，逗号分隔）
```

**策略参数配置示例：**

MA10 突破策略：
```ini
strategy_params = {"ma_period": 10, "volume_ratio_min": 1.0, "turnover_min": 0.3}
```

均线成交量策略：
```ini
strategy_params = {"max_market_cap": 200000, "min_slope_angle": 0, "max_slope_angle": 30, "max_volume_ratio": 3}
```

### 4. [market] - 行情 Pub/Sub 配置

```ini
[market]
snapshot_channel_prefix = market:snapshot    # 行情快照通道前缀
subscribe_pattern = market:snapshot:*        # 订阅模式
push_interval = 100                          # 推送间隔（毫秒）
```

### 5. [selection] - 股池 Stream 配置

```ini
[selection]
stream_key_prefix = selection:stream    # Stream Key 前缀
stream_maxlen = 10000                   # Stream 最大长度
consumer_group = selection_consumer     # 消费者组名称
consumer_name = consumer_01             # 消费者名称
```

### 6. [consumer] - 消费者配置

```ini
[consumer]
selection_wait_timeout = 30    # 等待选股池超时时间（秒）
max_snapshots = 1000           # 最大消费行情快照数
market_timeout = 60            # 行情数据消费超时时间（秒）
verbose = true                 # 是否打印详细日志
```

### 7. [logging] - 日志配置

```ini
[logging]
level = INFO                       # 日志级别: DEBUG, INFO, WARNING, ERROR, CRITICAL
log_file = logs/redis_service.log  # 日志文件路径
max_bytes = 10                     # 日志文件最大大小（MB）
backup_count = 5                   # 保留日志文件数量
console_output = true              # 是否输出到控制台
```

### 8. [performance] - 性能优化配置

```ini
[performance]
batch_size = 100        # 批量操作大小
thread_pool_size = 4    # 线程池大小
async_mode = false      # 是否启用异步模式
serializer = json       # 数据序列化方式: json, pickle, msgpack
```

## 配置加载方式

### 方式1: 默认配置文件

```bash
python main.py --mode full --date 20241008
```

系统会自动加载 `config/config.ini` 配置文件。

### 方式2: 指定配置文件

```bash
python main.py --mode full --date 20241008 --config /path/to/custom_config.ini
```

### 方式3: 程序中加载

```python
from config.config_loader import load_config, update_global_settings

# 加载配置
config = load_config('config/config.ini')

# 更新全局配置
update_global_settings('config/config.ini')
```

## 配置优先级

配置优先级从高到低：

1. **命令行参数** (如: `--date 20241008`)
2. **配置文件** (config.ini)
3. **代码默认值** (settings.py)

## 常见问题

### Q: 配置文件路径找不到？

A: 确保配置文件路径是相对于项目根目录的绝对路径或正确相对路径。建议使用绝对路径。

### Q: 策略参数如何配置？

A: 策略参数使用 JSON 格式字符串，需要确保 JSON 格式正确。可以使用在线 JSON 验证工具检查。

### Q: 如何切换不同的策略？

A: 修改 `strategy_id` 和对应的 `strategy_params`。例如，切换到均线成交量策略：

```ini
[backtest]
strategy_id = MA_VOLUME_STRATEGY
strategy_params = {"max_market_cap": 200000, "min_slope_angle": 0, "max_slope_angle": 30, "max_volume_ratio": 3}
```

### Q: 如何配置多个交易日？

A: 使用逗号分隔的日期列表：

```ini
[backtest]
trade_dates = 20241001,20241002,20241003,20241008,20241009
```

## 注意事项

1. **密码安全**: 生产环境中不要将明文密码提交到版本控制系统
2. **备份**: 修改配置前请备份原始配置文件
3. **格式**: INI 文件格式要求严格，注意不要有多余的空格或引号
4. **注释**: 以 `#` 开头的行为注释
5. **编码**: 配置文件使用 UTF-8 编码
