# 消息定义与业务流程

## 一、消息定义总览

本系统通过 Redis 实现两类核心数据的推送：

| 消息类型 | 存储方式 | Key 格式 | 用途 |
|---------|---------|---------|------|
| **行情快照** | Pub/Sub | `market:snapshot:{exchange}:{symbol}` | 广播实时行情数据给策略模块 |
| **选股股池** | Stream | `selection:stream:{date}` | 持久化选股结果，支持消费追更 |

---

## 二、行情快照（Market Snapshot）

### 2.1 通道定义

Pub/Sub 通道命名规范：`market:snapshot:{exchange}:{symbol}`

| 参数 | 说明 | 示例 |
|------|------|------|
| exchange | 交易所代码 | `SSE`（上交所）、`SZSE`（深交所） |
| symbol | 股票代码 | `600036`、`000001` |

**完整通道示例**：
- `market:snapshot:SSE:600036`  —— 招商银行上交所行情
- `market:snapshot:SZSE:000001` —— 平安银行深交所行情

### 2.2 消息结构

```json
{
    "type": "snapshot",
    "timestamp": 1703234567890,        // 毫秒时间戳（消息发送时间）
    "exchange": "SSE",                  // 交易所代码
    "symbol": "600036",                 // 股票代码
    "data": {
        "last_price": 32.56,             // 最新价（元）
        "volume": 12345678,               // 成交量（手）
        "amount": 3987654321,            // 成交额（元）
        "bid_price": [32.55, 32.54, 32.53, 32.52, 32.51],  // 买一到买五价格
        "bid_volume": [100, 200, 300, 400, 500],              // 买一到买五量（手）
        "ask_price": [32.57, 32.58, 32.59, 32.60, 32.61],  // 卖一到卖五价格
        "ask_volume": [150, 250, 350, 450, 550],              // 卖一到卖五量（手）
        "date": "20260317",              // 行情日期（YYYYMMDD）
        "time": "14:45:15"               // 行情时间（HH:MM:SS）
    }
}
```

### 2.3 行情快照业务流程

```
┌──────────────┐    ┌──────────────────────────┐    ┌──────────────┐
│    MySQL     │    │   MarketService          │    │    Redis     │
│stock_daily_  │    │   (redis_service)        │    │    Pub/Sub   │
│    data      │    │                          │    │              │
└──────┬───────┘    └──────────┬───────────────┘    └──────┬───────┘
       │                       │                          │
       │  1. 读取最新交易日数据 │                          │
       │──────────────────────►│                          │
       │                       │                          │
       │                       │  2. 转换为标准消息结构     │
       │                       │  Transformer              │
       │                       │                          │
       │                       │  3. 批量发布到 Pub/Sub    │
       │                       │─────────────────────────►│
       │                       │  publish_snapshot_batch() │
       │                       │                          │
       │                       │                          │  4. 广播给所有订阅者
       │                       │                          │──────────────►
       │                       │                          │     策略模块
       │                       │                          │    (多订阅者)
       │                       │                          │──────────────►
       │                       │                          │     监控模块
       │                       │                          │    (多订阅者)
```

#### 详细步骤说明

| 步骤 | 模块 | 动作 | 关键方法/配置 |
|------|------|------|--------------|
| **1** | DbReader | 从 MySQL 读取最新交易日行情数据 | `read_latest_snapshots(trade_date)` |
| **2** | Transformer | 将 DataFrame 转换为标准消息结构 | `batch_snapshot_items(df)` |
| **3** | RedisPublisher | 批量发布到 Pub/Sub（pipeline 优化） | `publish_snapshot_batch(snapshots)` |
| **4** | 策略模块 | 订阅通道，接收实时行情 | `pubsub.subscribe("market:snapshot:SSE:600036")` |

#### 服务端实现

**推送代码**（`redis_service/publisher.py`）：
```python
def publish_snapshot_batch(self, snapshots: list[dict]) -> dict:
    """批量推送行情快照"""
    pipe = self._client.pipeline(transaction=False)
    for item in snapshots:
        channel = f"market:snapshot:{item['exchange']}:{item['symbol']}"
        payload = json.dumps(item["message"], ensure_ascii=False)
        pipe.publish(channel, payload)
    results = pipe.execute()  # 批量执行，减少网络往返
```

**调度逻辑**（`redis_service/service.py`）：
```python
def _snapshot_loop(self):
    """行情快照推送循环（独立线程）"""
    while not self._stop_event.is_set():
        self.run_once_snapshot()              # 读 MySQL → 推 Redis
        self._stop_event.wait(snapshot_interval)  # 默认 3 秒轮询
```

#### 客户端（策略模块）消费示例

```python
import redis
import json

client = redis.Redis(host="localhost", port=6379, decode_responses=True)
pubsub = client.pubsub()

# 订阅单只股票
pubsub.subscribe("market:snapshot:SSE:600036")

# 订阅全部上交所股票（通配符需在业务层循环订阅）
for symbol in stock_list:
    pubsub.subscribe(f"market:snapshot:SSE:{symbol}")

for message in pubsub.listen():
    if message["type"] == "message":
        data = json.loads(message["data"])
        print(f"收到行情: {data['symbol']} 价格={data['data']['last_price']}")
```

### 2.4 特点说明

| 特性 | 说明 |
|------|------|
| **广播特性** | 一个发布者可被多个订阅者接收，适合多策略模块同时消费 |
| **无持久化** | 只有在线订阅者能收到消息，离线期间的消息会丢失 |
| **低延迟** | 实时推送，适合高频行情场景 |
| **批量优化** | 使用 `pipeline` 批量发送，减少网络往返 |

## 三、选股股池（Stock Selection）

### 3.1 Key 定义

Stream Key 命名规范：`selection:stream:{date}`

| 参数 | 说明 | 示例 |
|------|------|------|
| date | 选股日期 | `20260317`（YYYYMMDD 格式） |

**完整 Key 示例**：
- `selection:stream:20260317` —— 2026年3月17日的选股股池

### 3.2 消息结构

```json
{
    "type": "stock_selection",
    "version": "1.0",
    "timestamp": 1703234567890,
    "batch_id": "SELECT_20260317_001",    // 选股批次ID（全局唯一）
    "strategy_id": "MA10_BREAKTHROUGH",    // 选股策略ID
    "total_count": 50,                     // 本次选股总数
    "stocks": [
        {
            "symbol": "600036",
            "exchange": "SSE",
            "name": "招商银行",
            "basic_info": {
                "prev_close": 32.50,        // 昨收价
                "ma10": 31.80,               // 10日均线
                "ma5_high": 33.00,          // 近5日最高价
                "volume_ratio": 1.2,        // 量比
                "turnover_rate": 0.5        // 换手率
            },
            "minute_volume_5d": [          // 昨日每5分钟成交量（5天）
                {"time": "09:35", "volume": 1234},
                {"time": "09:40", "volume": 2345},
                // ... 共 48 个点（9:30-15:00）
            ],
            "technical_indicators": {
                "ma5": 31.20,
                "ma10": 31.80,
                "ma20": 32.10,
                "vol_ma5": 4567890,
                "vol_ma10": 5678901
            },
            "fundamental_data": {
                "pe": 8.5,
                "pb": 1.2,
                "market_cap": 820000      // 市值（百万）
            }
        },
        // ... 更多股票
    ]

```

### 3.3 选股股池业务流程

```
┌──────────────┐    ┌──────────────────────────┐    ┌──────────────┐
│    MySQL     │    │   MarketService          │    │    Redis     │
│stock_selection│    │   (redis_service)        │    │   Stream     │
│    data      │    │                          │    │              │
└──────┬───────┘    └──────────┬───────────────┘    └──────┬───────┘
       │                       │                          │
       │  1. 读取指定日期选股  │                          │
       │──────────────────────►│                          │
       │                       │                          │
       │                       │  2. 补充技术指标/基本面   │
       │                       │  计算均线、市值等        │
       │                       │                          │
       │                       │  3. 转换为标准消息结构     │
       │                       │  Transformer              │
       │                       │                          │
       │                       │  4. 写入 Stream           │
       │                       │─────────────────────────►│
       │                       │  push_stock_selection()  │
       │                       │                          │
       │                       │                          │  5. 策略模块按需读取
       │                       │                          │──────────────►
       │                       │                          │     消费者 A
       │                       │                          │──────────────►
       │                       │                          │     消费者 B
       │                       │                          │    (支持追更)
```

#### 详细步骤说明

| 步骤 | 模块 | 动作 | 关键方法/配置 |
|------|------|------|--------------|
| **1** | DbReader | 从 `stock_selection` 表读取指定日期选股结果 | `read_stock_selection(trade_date, strategy_id)` |
| **2** | DbReader | 补充技术指标（MA5/MA10/MA20）和基本面数据 | `read_technical_indicators()`, `read_fundamental_data()` |
| **3** | Transformer | 构建选股消息结构（含 batch_id、stocks 列表） | `selection_message(df, trade_date, strategy_id, db_reader)` |
| **4** | RedisPublisher | 写入 Stream，设置 maxlen=10000 | `push_stock_selection(date_compact, message)` |
| **5** | 策略模块 | 从 Stream 消费，支持断点续传 | `xread({key: last_id})` |

#### 服务端实现

**写入代码**（`redis_service/publisher.py`）：
```python
def push_stock_selection(self, date: str, message: dict) -> str:
    """将选股结果写入 Redis Stream"""
    stream_key = f"selection:stream:{date}"
    stream_entry = {"data": json.dumps(message, ensure_ascii=False)}
    entry_id = self._client.xadd(
        stream_key,
        stream_entry,
        maxlen=10000,       # 保留最近 10000 条
        approximate=True,   # 近似 maxlen，性能更好
    )
    return entry_id
```

**调度逻辑**（`redis_service/service.py`）：
```python
def _selection_loop(self):
    """选股数据推送循环（独立线程）"""
    while not self._stop_event.is_set():
        trade_date = datetime.now().strftime("%Y-%m-%d")
        self.run_once_selection(trade_date)  # 读 MySQL → 写 Redis Stream
        self._stop_event.wait(selection_interval)  # 默认 60 秒轮询
```

#### 客户端（策略模块）消费示例

```python
import redis
import json

client = redis.Redis(host="localhost", port=6379, decode_responses=True)

# 1. 从头开始消费（全量）
messages = client.xread(
    {"selection:stream:20260317": "0-0"},  # 0-0 表示从最早消息开始
    count=100,                            # 每次最多读 100 条
)

# 2. 继续消费（增量）
last_id = "1703234567890-0"  # 上次消费到的 entry_id
messages = client.xread(
    {"selection:stream:20260317": last_id},
    count=100,
    block=5000,  # 阻塞 5 秒等待新消息
)

for stream, items in messages:
    for entry_id, fields in items:
        data = json.loads(fields["data"])
        print(f"选股批次: {data['batch_id']}, 股票数: {data['total_count']}")
        for stock in data["stocks"]:
            print(f"  {stock['symbol']} {stock['name']}")
        # 记录 entry_id，下次从该 ID 继续
        last_id = entry_id
```

### 3.4 特点说明

| 特性 | 说明 |
|------|------|
| **持久化存储** | 数据持久化在 Redis Stream，消费者离线期间消息不会丢失 |
| **支持追更** | 消费者可从任意 entry_id 继续消费，适合断点续传 |
| **多消费者** | 支持多个消费者同时读取，互不影响（非竞态） |
| **自动修剪** | 设置 maxlen，自动清理旧数据，防止无限增长 |
| **有序保证** | 消息按写入顺序存储，entry_id 包含时间戳 |

## 四、对比总结

| 维度 | 行情快照（Pub/Sub） | 选股股池（Stream） |
|------|---------------------|-------------------|
| **数据特征** | 高频、实时、无历史 | 低频、批量、需追溯 |
| **持久化** | ❌ 无 | ✅ 有 |
| **离线消费** | ❌ 离线期间消息丢失 | ✅ 支持断点续传 |
| **消费者数量** | 1:N（广播） | 1:N（多读） |
| **适用场景** | 实时行情推送 | 选股结果持久化、回放 |
| **数据结构** | Channel | Stream Key |
| **性能特点** | 低延迟、高吞吐 | 支持历史查询、按需读取 |
| **内存管理** | 自动清理（无存储） | maxlen 自动修剪 |
